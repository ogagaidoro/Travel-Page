# Travel Page

A responsive travel website designed with a clean and visually engaging layout for presenting travel-related content.

## 🚀 Live Demo

https://ogagaidoro.github.io/Travel-Page/

## 🛠️ Technologies

* HTML5
* CSS3
* Responsive Web Design

## ✨ Features

* Responsive navigation
* Hero section
* Travel-focused content sections
* Image-based content
* Call-to-action sections
* Responsive layout
* Mobile-friendly design

## 📱 Responsive Design

The website adapts to different screen sizes to provide a consistent browsing experience on desktop, tablet, and mobile devices.

## 🎯 Purpose

This project was built to improve my skills in responsive web design, layout composition, typography, spacing, and creating visually engaging interfaces.
